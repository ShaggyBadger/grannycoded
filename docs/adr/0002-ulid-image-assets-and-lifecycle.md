# ADR-0002: Store images as ULID-backed Linode assets

Store image objects in the existing Linode bucket under ULID-based keys, with a single `ImageAsset` row holding the ULID, display name, source path, checksum, visibility, and lifecycle state. `ProductImageAsset`, `BrandSettings`, and `BlogPostPage` link public assets to their content; custom inquiries link private assets. Keep the bucket private by default, grant public-read only to public site images, and keep customer reference photos private behind a staff-authorized route. Delay deletion for 30 days after an asset loses its last database reference, and retain a separate delayed cleanup queue for legacy Oscar product-image and inquiry fields. Wagtail-managed images follow Wagtail's lifecycle. Keep CSS, JavaScript, fonts, and other static files in the application; upload images through a dedicated idempotent management command rather than `collectstatic`.
