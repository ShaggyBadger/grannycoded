# Blog tags and filters

## Goal

Let editors assign reusable tags to blog posts, let readers filter the blog by
tag, and apply appropriate tags to the existing posts.

## Relevant files

- `backend/home/models.py` and a new `home` migration
- `backend/home/templates/home/blog_index_page.html`
- `backend/home/templates/home/blog_post_page.html`
- `backend/home/tests.py`
- Local Wagtail blog content in the Compose database

## Steps

1. Add Wagtail-compatible tag relationships to blog posts and admin panels.
2. Add query-string tag filtering, visible filter links, and tag labels on posts.
3. Test tagging, filtering, pagination, and existing untagged posts.
4. Apply the migration to the local development database and tag the existing
   posts based on their published content.

## Verification

Run Django checks, the relevant home tests, full tests if practical, and
`makemigrations --check` inside Docker. Verify the local blog and post records
after applying the migration; do not connect to or modify production.
